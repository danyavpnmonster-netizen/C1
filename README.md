# Sunrise Bay

Открытая (open source) 3D-игра в жанре «криминальной песочницы» с открытым миром — в духе классических игр вроде GTA San Andreas, но с собственным городом, механиками и графикой. Работает прямо в браузере (ПК и телефон), написана на JavaScript + [Three.js](https://threejs.org), без сборки.

## Что есть в игре
- **Открытый город** 10×10 кварталов: ступенчатые небоскрёбы и стеклянные башни в центре, кирпичные дома, частный сектор с домиками и двориками на окраинах, кусты и цветы на тротуарах, парки с трамплинами, пляж с пальмами.
- **Дома с комнатами**: у частных домов и подъездов зелёное кольцо у двери. Внутри гостиная, спальня, кухня и ванная с мебелью; в каждом доме свои обои и иногда находки — деньги, аптечка, патроны.
- **Магазины, в которые можно зайти** (жёлтое кольцо у двери): «Продукты 24/7» — еда и аптечки, «Оружейная» — патроны и бронежилеты, «Одежда» — смена костюма.
- **Пешком и на машине**: ходьба, бег, прыжки, драка; 5 типов машин (седан, спорткар, фургон, такси, полиция).
- **Оружие**: кулаки и пистолет (патроны — синие ящики на тротуарах), трассеры пуль, стены останавливают выстрелы.
- **Физика машин**: шины с ограниченным сцеплением (занос, дрифт на ручнике, пробуксовка), перенос веса при разгоне и торможении, крен кузова, система стабилизации, мокрая дорога в дождь, удары с учётом масс и точки контакта (удар в угол закручивает), следы шин и визг.
- **Нитро**: ускорение в машине на Shift, шкала восстанавливается со временем.
- **Район банды** (зелёная зона на карте): бандиты стреляют, если подойти близко; за победу выпадают деньги и патроны.
- **Бронежилеты**: броня принимает урон на себя (синяя полоска над здоровьем).
- **Погода**: дождь с каплями и шумом, небо темнеет.
- **Автонастройка графики**: если игра тормозит, качество само понижается (удобно для телефонов).
- **Угон машин** (F): водитель выскакивает и убегает.
- **Люди**: лицо, волосы, шея, руки с локтями и кистями, ноги с коленями и обувью; мужчины и женщины разного роста и телосложения; колени и локти сгибаются при ходьбе, на бегу корпус наклоняется.
- **Машины**: кузова со скруглёнными формами, стеклянной кабиной, арками колёс, фарами, бамперами и зеркалами; у каждого типа свой силуэт.
- **Живой город**: трафик ездит по полосам и тормозит перед препятствиями, пешеходы ходят по тротуарам и переходят улицы.
- **Розыск 1–5 звёзд**: полиция преследует по улицам, останавливается рядом, полицейские выходят из машины и бегут за вами пешком — при 1 звезде пытаются арестовать, с 2 звёзд стреляют. Если уехать, они возвращаются в машину. Можно уйти от погони или перекраситься в мастерской (**$** на карте).
- **Миссии**: Курьер (К), Такси (Т), Гонка по чекпоинтам (Г), Угон на заказ (У) — с таймером и наградой.
- **Большая карта** на клавишу M.
- **Смена дня и ночи** (горящие окна, фонари, фары), мини-карта, деньги, аптечки, взрывы машин, процедурный звук.
- **Сенсорное управление** на телефоне (джойстик + кнопки), сохранение денег.

## Android-приложение (APK)
Готовый файл: [`dist/SunriseBay.apk`](dist/SunriseBay.apk). Скачайте его на телефон, откройте и разрешите установку из этого источника. Игра работает без интернета.

Собрать APK самому (нужны JDK 17+ и Android SDK с platform 34):
```bash
cd android
echo "sdk.dir=/путь/к/android-sdk" > local.properties
./gradlew assembleRelease
# файл: android/app/build/outputs/apk/release/app-release.apk
```

## Игра вдвоём по Wi-Fi
Работает в Android-приложении (браузер не умеет напрямую соединять телефоны).
1. Подключите оба телефона к одной сети Wi-Fi — или включите точку доступа на одном телефоне и подключите к ней второй.
2. На обоих откройте игру → «ВДВОЁМ».
3. Первый нажимает «Создать игру», второй выбирает найденную игру в списке (или вводит IP-адрес, который показан у первого).

Каждый видит второго игрока (оранжевая точка на карте), его машину, можно таранить и стрелять друг в друга. Время суток и погода общие, а прохожие, трафик и полиция у каждого свои. Порты: TCP 47777 (игра), UDP 47778 (поиск игр).

## Запуск в браузере
Нужен любой локальный веб-сервер (модули ES не грузятся через `file://`):

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Тест-режим
Кнопка «ТЕСТ-РЕЖИМ» на стартовом экране: без полиции, с панелью физики (скорость, перегрузки, угол заноса, вращение, пробуксовка, сцепление) и быстрыми действиями: 1–5 — выбрать машину, R — сброс, G — к трамплину, Y — на длинную прямую, K — машины-препятствия, T — дождь. Прогресс в этом режиме не сохраняется.

## Управление
| Клавиша | Действие |
|---|---|
| W A S D / стрелки | движение; в машине — газ, тормоз/задний ход, руль |
| Мышь | камера (клик — захват курсора, Esc — отпустить) |
| Shift | бег; в машине — нитро |
| Пробел | прыжок / ручной тормоз |
| F | сесть в машину / выйти |
| ЛКМ, E | удар / выстрел |
| Q, 1, 2 | сменить оружие |
| M | большая карта |
| H | сигнал |

| `src/traffic.js` | ИИ трафика и дорожная сеть |

| `src/gangs.js` | район банды и бандиты |

| `src/homes.js` | квартиры с комнатами |

| `src/missions.js` | миссии |
| `src/hud.js` | интерфейс и мини-карта |
| `src/input.js` | клавиатура, мышь, тач |
| `src/audio.js` | звук на WebAudio |
